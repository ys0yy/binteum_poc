# binteum_poc


## 실행 방법
1. 상단 GitHub Pages 링크 또는 `index.html` 파일을 브라우저로 열어 실행합니다.
2. 카페 카드의 [여유], [보통], [혼잡] 버튼을 눌러 제보를 입력합니다.
3. 제보 건수와 조건에 따라 화면의 '현재 상태'와 '신뢰도'가 실시간으로 변경되는 것을 확인합니다.

## 혼잡도 산출 및 판단 기준
1. 유효 시간 범위: 최근 60분 이내의 제보 데이터만 사용합니다.
2. 최소 제보 수: 
   - 60분 내 제보가 3건 미만일 경우 ➔정보 부족으로 표시
   - 제보가 3건 이상일 경우 ➔ 최다 제보 상태로 현재 혼잡도 출력
3. 동점 처리: 최다 제보 건수가 동률일 경우(예: 여유 2건, 보통 2건) ➔ 가장 최근에 입력된 제보 상태를 우선 반영하고 신뢰도를 '의견 엇갈림'으로 표시
